## B · Günlük kullanım

Önerilen sıra (her biri ayrı küçük plan ve onay):

1. **Terminal seçimi** — Settings → Suggestions: iTerm, Terminal, Ghostty, Warp. Rust `launch_claude` uygulama adını izinli listeden alır; her terminalin script açma yolu tek tek denenir.
2. **Erteleme ve susturma** — satıra sağ tık: "Snooze for a day", "Mute this repository", "Copy link". Ertelenen öğe süre bitince yeniden yeni sayılır; susturulan repo GitHub repo listesine (gizle) eklenir.
3. **Bildirim kontrolü** — şerit başına bildirim aç/kapa; sessiz saatler (ör. 22:00–08:00), bu sürede bildirim yerine yalnız rozet.
4. **GHBar'dan kalanlar** — profil başlığı (avatar, yıldız/takipçi), kalan API kotası (alt bilgi: hiç / azalınca / her zaman), repo listesi için kutucuklu liste, çevrimdışıyken "showing what was there 5m ago".
5. **Claude oturumuna tıklayınca doğru terminal** — oturumun terminal uygulamasını öğrenmek için `SessionStart`'ta ek bilgi gerekir; önce araştırma, olmazsa terminal uygulamasını öne getirme kalır.
