## B · Günlük kullanım

Durum: beşi de uygulandı (henüz commit'lenmedi, kullanıcı testi bekliyor).

1. **Terminal seçimi** — Settings → Suggestions: iTerm, Terminal, Ghostty, Warp. Rust `launch_claude` uygulama adını izinli listeden alır. Denendi: dördü de `open -a <App> x.command` ile script'i çalıştırıyor (Ghostty 1.3.1, Warp 2026.09).
2. **Erteleme ve susturma** — satıra sağ tık (yerel menü): "Copy Link" (Rust `copy_text`, pbcopy; menü geri çağrısı WebKit'te kullanıcı jesti sayılmadığı için), "Snooze for a Day" (grup satırında "Snooze N Items"), "Mute owner/name" (yalnız GitHub). Ertelenen öğe süre bitince görülmemiş ve bildirilmemiş sayılır; susturma gizle listesine ekler (yalnız-bunlar modunda listeden çıkarır) ve izlenen branch'lerden siler.
3. **Bildirim kontrolü** — Settings → General → Notifications: şerit başına anahtar, sessiz saatler (varsayılan 22:00–08:00, kapalı). Sessiz saatte gelen öğe bildirilmiş sayılır; sonradan bildirim gelmez, rozet kalır. Claude hatırlatma kartları Agents anahtarına uyar.
4. **GHBar'dan kalanlar** — profil başlığı (avatar, yıldız/takipçi; ada tıklayınca GitHub profili; sorgu maliyeti değişmedi), kalan API kotası alt bilgisi (Settings → GitHub → API: Never / When low / Always; varsayılan çeyreğin altında), repo kutucuk listesi (`repos.json` sayaçları, hesap değişince sıfırlanır; elle "owner/name" ekleme), kaynak hata verince "Showing what was there 5m ago".
5. **Claude oturumuna tıklayınca doğru terminal** — Araştırma: hook girdisinde terminal bilgisi yok, ama http hook header'ları `allowedEnvVars` ile ortam değişkeni taşıyabiliyor. Hook'lar `X-Hither-Terminal: $TERM_PROGRAM` gönderiyor (eski kurulumda "hooks are out of date" şeridi çıkar). Oturumun terminali öne gelir; bilinmiyorsa ayardaki terminal. Sekme düzeyi (iTerm `ITERM_SESSION_ID` + AppleScript) Automation izni, `NSAppleEventsUsageDescription` ve imza yetkisi ister; ayrı karar.

## C · GitHub şeridini derinleştirme (uygulandı)

1. **Birleştirmeye hazır** — kendi PR'ın onaylı, check'leri yeşil ve taslak değilse "Ready to Merge" bölümüne çıkar (bildirim gelir).
2. **Çakışmalar** — `mergeable: CONFLICTING` olan PR'ın "Merge Conflicts" bölümüne çıkar; Suggestions'ta "Open in Claude" kartı (`merge-conflicts` şablonu, yalnız repo ve numara).
3. **Bahsedilmeler ve atananlar** — "Mentioned" ve "Assigned to You" bölümleri; kapsam kendi PR aramalarınla aynı (organizasyon ya da yalnız-bunlar listesi), gizle listesi uygulanır. Settings → GitHub → Sections'tan kapatılabilir.
4. **Gecikmiş review** — Settings → GitHub: "Flag review requests older than" (varsayılan 24 saat, 0 kapalı). Süre PR'ın açıldığı andan sayılır (review isteğinin zamanı ek sorgu ister). Satırın yaşı ve halkası turuncu olur.
5. **Satırdan hızlı işlemler** — sağ tık: "Copy Branch", "Checkout in <terminal>" (Rust `checkout_pr`: klasöre gider, `gh pr checkout <n>` çalıştırır, kabuk açık kalır). Repo klasörü Claude oturumlarından ya da öneri kartından öğrenilmiş olmalı; bilinmiyorsa seçenek pasif görünür.
