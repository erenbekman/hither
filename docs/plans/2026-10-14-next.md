## B · Günlük kullanım

Durum: beşi de uygulandı (henüz commit'lenmedi, kullanıcı testi bekliyor).

1. **Terminal seçimi** — Settings → Suggestions: iTerm, Terminal, Ghostty, Warp. Rust `launch_claude` uygulama adını izinli listeden alır. Denendi: dördü de `open -a <App> x.command` ile script'i çalıştırıyor (Ghostty 1.3.1, Warp 2026.09).
2. **Erteleme ve susturma** — satıra sağ tık (yerel menü): "Copy Link" (Rust `copy_text`, pbcopy; menü geri çağrısı WebKit'te kullanıcı jesti sayılmadığı için), "Snooze for a Day" (grup satırında "Snooze N Items"), "Mute owner/name" (yalnız GitHub). Ertelenen öğe süre bitince görülmemiş ve bildirilmemiş sayılır; susturma gizle listesine ekler (yalnız-bunlar modunda listeden çıkarır) ve izlenen branch'lerden siler.
3. **Bildirim kontrolü** — Settings → General → Notifications: şerit başına anahtar, sessiz saatler (varsayılan 22:00–08:00, kapalı). Sessiz saatte gelen öğe bildirilmiş sayılır; sonradan bildirim gelmez, rozet kalır. Claude hatırlatma kartları Agents anahtarına uyar.
4. **GHBar'dan kalanlar** — profil başlığı (avatar, yıldız/takipçi; ada tıklayınca GitHub profili; sorgu maliyeti değişmedi), kalan API kotası alt bilgisi (Settings → GitHub → API: Never / When low / Always; varsayılan çeyreğin altında), repo kutucuk listesi (`repos.json` sayaçları, hesap değişince sıfırlanır; elle "owner/name" ekleme), kaynak hata verince "Showing what was there 5m ago".
5. **Claude oturumuna tıklayınca doğru terminal** — Araştırma: hook girdisinde terminal bilgisi yok, ama http hook header'ları `allowedEnvVars` ile ortam değişkeni taşıyabiliyor. Hook'lar `X-Hither-Terminal: $TERM_PROGRAM` gönderiyor (eski kurulumda "hooks are out of date" şeridi çıkar). Oturumun terminali öne gelir; bilinmiyorsa ayardaki terminal. Sekme düzeyi (iTerm `ITERM_SESSION_ID` + AppleScript) Automation izni, `NSAppleEventsUsageDescription` ve imza yetkisi ister; ayrı karar.

## C · GitHub şeridini derinleştirme (uygulandı)

1. **Birleştirmeye hazır** — kendi PR'ın onaylı, check'leri yeşil ve taslak değilse "Ready to Merge" bölümüne çıkar (bildirim gelir).
2. **Çakışmalar** — `mergeable: CONFLICTING` olan PR'ın "Merge Conflicts" bölümüne çıkar; Suggestions'ta "Open in Claude" kartı (`merge-conflicts` şablonu, yalnız repo ve numara).
3. **Bahsedilmeler ve atananlar** — "Mentioned" ve "Assigned to You" bölümleri; kapsam kendi PR aramalarınla aynı (organizasyon ya da yalnız-bunlar listesi), gizle listesi uygulanır. Settings → GitHub → Sections'tan kapatılabilir.
4. **Gecikmiş review** — Settings → GitHub: "Flag review requests older than" (varsayılan 24 saat, 0 kapalı). Süre PR'ın açıldığı andan sayılır (review isteğinin zamanı ek sorgu ister). Satırın yaşı ve halkası turuncu olur.
5. **Satırdan hızlı işlemler** — sağ tık: "Copy Branch", "Checkout in <terminal>" (Rust `checkout_pr`: klasöre gider, `gh pr checkout <n>` çalıştırır, kabuk açık kalır). Repo klasörü Claude oturumlarından ya da öneri kartından öğrenilmiş olmalı; bilinmiyorsa seçenek pasif görünür.

## D · GHBar kıyası sonrası (uygulandı)

1. **Temizlik ve ergonomi** — Suggestions açılış hatası görünür; cask ve site metinleri düzeldi; Sections (Settings → General) üç şeridi kapsar; özetler ve gizlenen kartlar yalnız ilk yenilemeden sonra budanır (açılışta silinmiyordu, düzeldi); Esc (aramayı kapatır, sonra paneli gizler), ⌘O profil, ⌘⇧A ve tray menüsünde "Mark All as Seen"; panel açılışında yenileme 30 sn'de bir; uykudan uyanınca yenileme; Outgoing ve yalnız-bunlar listesi için "Open Settings" butonlu boş durumlar.
2. **Menü çubuğu durumu** — görülmemiş kritik öğe varken noktalı ikon, bir kaynak hata verirken soluk ikon (template varyantlar, `scripts/icons.swift`); Rust `set_tray`.
3. **New Activity** — `GET /notifications?participating=true` (son 14 gün, yorum, bahsetme, kendi thread'in, durum değişimi; PR ve issue). GitHub'da açınca okundu olur ve sonraki yenilemede düşer; Hither yazma yapmaz. Yeni kaynak ilk çalıştırmada bildirim göndermez (board'da kaynak id'si üzerinden). Aynı hata iki kaynaktan gelirse tek şerit gösterilir.
4. **Arama ve açılışta son liste** — panelde yazmaya başlayınca (ya da ⌘F) süzme; başlık, repo, #numara, @kişi, branch. Son liste `board.json`'a yazılır, açılışta ilk yenilemeden önce gösterilir (başka hesaba aitse gösterilmez).


## E · GHBar farkları, gh'siz giriş, Intel, sekme odağı, Codex (uygulandı)

1. **Küçük farklar** — Incoming'de organizasyon hapı ("Your repositories" / "Assigned to you in …", yerel menüden seçim); Settings → GitHub'da izlenen hesaplar ekle/çıkar listesi; satır, sekme ve butonlarda VoiceOver etiketleri (yaş sözle: "3 hours ago").
2. **Sağ tık menüsü** — yeni menü açılınca bir önceki kapatılır (Tauri, menü kapanınca öğenin kanalını siler; `popup()` dönünce hemen kapatmak tıklamayı kaybedebilirdi).
3. **gh olmadan giriş** — GitHub OAuth device flow (`github.com/login/*`, `tauri-plugin-http` ile; CORS yok). Token Keychain'de `github-token`; yoksa `gh auth token`. Özel repolar için `repo`, değilse `public_repo`; ikisinde de `read:org notifications`. Client id `src/core/github-app.ts` → `GITHUB_CLIENT_ID`; boşken giriş butonu görünmez, ipuçları `gh auth login` der ve `release.sh` durur.
4. **İlk açılış penceresi** — `onboarded` kapalıyken açılışta: GitHub hesabı (gh ya da giriş), Claude Code ve Codex hook'ları, girişte başlatma, "Start Using Hither".
5. **Intel** — `brew install rustup` (keg-only, Homebrew rust'ına dokunmaz) + iki hedef; `release.sh` universal derler, DMG `Hither_<v>_universal.dmg`, `latest.json`'da arm64 ve x86_64 aynı paket, cask'te arm64 şartı kalktı.
6. **Sekmeye odak** — hook'lar `$ITERM_SESSION_ID` de gönderir; iTerm'de tam oturum, Ghostty'de klasörü eşleşen terminal (AppleScript, ilk kullanımda macOS Automation izni); Terminal ve Warp'ta uygulama öne gelir.
7. **Codex** — `~/.codex/hooks.json`'a `curl` komutu (async, `|| true`, bekletmez); Codex'te bir kez `/hooks` ile onay. `PermissionRequest` → "Codex needs your permission to use …"; Agents satırında "Codex" etiketi.

## F · Sadelik (uygulandı, `docs/specs/2026-10-14-simplicity-design.md`)
