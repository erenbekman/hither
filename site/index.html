Incoming

Pull requests and issues others opened in your repositories, reviews waiting on you, changes requested on yours. One GraphQL request per refresh.

Outgoing

Checks on your pull requests and your main branches, Laravel Forge deployments, new and spiking Sentry errors.

Agents

Claude Code sessions that are working, finished or waiting for you, and pull requests opened by coding agents.

Suggestions

Deterministic rules turn those signals into one-click actions, such as opening Claude Code in the right folder when a check fails after a deploy.

Your data stays on your Mac

  • Hither talks only to GitHub, Forge and Sentry, using your own tokens. Tokens live in the macOS Keychain.
  • Nothing is sent to Claude unless you press a button that says so. Prompts carry only ids such as a repository and a pull request number, never titles, logs or error text.
  • The Claude Code hook listener accepts connections from 127.0.0.1 only and checks a random token.
  • Errors are shown as errors. An empty list always means there is nothing to show.
